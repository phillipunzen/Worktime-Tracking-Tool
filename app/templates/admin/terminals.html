Ohne PIN genügt die Personal-/Ausweisnummer, z. B. für einen RFID-Leser. Dann kann aber jeder mit bekannter Nummer für andere stempeln.

So geht's

  1. Terminal anlegen und den geheimen Link auf dem Gerät öffnen.
  2. Den Link als Lesezeichen bzw. „Zum Home-Bildschirm“ speichern, idealerweise im Kiosk-/Vollbildmodus.
  3. Allen Mitarbeitern unter Benutzer eine Personalnummer geben. Die PIN setzt der Admin oder der Mitarbeiter selbst unter Mein Konto.
  4. Geht ein Gerät verloren, den Link erneuern oder das Terminal sperren.
